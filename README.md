Smart Personal Expense & Budget Manager

Project Overview

The Smart Personal Expense & Budget Manager is a C++ console-based application that helps users record daily expenses, manage a budget, monitor spending, and generate expense reports.

Objectives

- Record and categorize personal expenses.
- Set a spending budget.
- Track total expenses and remaining budget.
- Generate category-wise expense reports.
- Store records permanently using file handling.

Features

- Set a budget
- Add and view expenses
- Categorize expenses
- Calculate total spending
- Display budget warnings
- Generate expense reports
- Save expense and budget data in files

Technologies Used

- Language: C++
- Concepts: Object-Oriented Programming
- Storage: File handling
- Libraries: iostream, fstream, vector, string, iomanip

OOP Concepts Demonstrated

- Classes and objects
- Encapsulation
- Inheritance
- Abstraction
- Runtime polymorphism
- Constructors
- Exception handling

Files

- "main.cpp" — Complete application source code
- "README.md" — Project documentation
- "expenses.txt" — Created when expense records are saved
- "budget.txt" — Created when the budget is saved

How to Run

1. Download or clone this repository.
2. Compile "main.cpp" using a C++ compiler that supports C++11 or later.
3. Run the compiled program.
4. Follow the menu displayed in the terminal.

Example compilation command:

g++ -std=c++11 main.cpp -o expense_manager

Run on Windows:

expense_manager.exe
